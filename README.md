# EEG RSI Scientist

让 AI 从真实 EEG 实验和反馈中学习可迁移的科研方法，并检验它是否更擅长改进下一代研究者。

内环提出假设、设计实验、形成证据；外环修改研究策略，在新问题上比较改进前后。EEG 表征分析是目前的实验场。一次任务完成、一次较好分数或一份新 skill 都不等于 RSI。

## 日常使用

日常只需辨认三个部分：`src/`是实现，`tasks/`是要研究的问题与接口，`docs/`是设计和证据说明。`tests/`用于检查实现，`config/`和`scripts/`用于环境与同步；`knowledge/`、`skills/`、`registry/`分别放领域材料、方法提示和资源登记。它们是否提供给受测AI由实验条件决定。

本地用于开发、阅读和本轮研究者的工具会话；火山云执行新的 EEG 科学计算。已有的 NCC 控制器可通过 SSH 把冻结候选交给火山云 Docker，但其原生模型通道当前授权失效，不能视为已恢复。受限额管理的原生 Builder 分析、受测研究者会话和 Docker 候选沙箱分别记录。GitHub 保存共同的 main，旧源码与过程记录保留在 Git 历史、归档标签和原冻结证据目录。

已配置环境中，从仓库根安装当前项目：

```bash
python -m pip install --no-deps -e .
python -m eegfm --help
python -m pytest -q
```

新环境先按[机器说明](docs/workspaces.md)安装 CPU 科学依赖；`dev` 包含测试与科学依赖，`plots` 和 `reve` 按需添加。Linux 负责受限 Agent、进程和沙箱执行。Windows 可编辑代码、阅读结果并运行可移植检查。

代码在 src/eegfm/，测试在 tests/，任务定义在 tasks/。运行产物、数据、权重和私有参考不进 Git。唯一正式本地工程为 X:/projects/EEG-AI-Scientist。

## 当前事实

本轮 EEG 分析发现：拟合样本会影响“属性是否已被移除”的判断；中央通道差异表示能读出全头平均难以读出的运动想象功率差。与三个随机初始化模型的比较显示，这个预训练检查点的优势主要出现在空间差异读出上，已通过独立数值复核；比较使用已查看数据，仍属探索。

独立编码研究者已在合成任务和真实 EEG 读出任务上完成写代码、拟合、验证选择、冻结、测试与报告。真实 EEG 的全部参数、1,008 行预测和统计复算通过，得到的是已知的负结果：新读出没有可靠分类增益。这证明了本轮执行链可运行，不证明科研能力或 RSI 提升。八次研究决策比较因未申明的共同历史背景而不具备正式选择资格；论文评价也仍有未完成的条件对应。进度、实际代码与报告入口集中在[本轮结果](docs/research/evidence-guided-results.md)。

新增两个已知机制的替代分类头，用来检验 AI 是否会把“干预后输出改变”过度解释成属性依赖。数值构造和独立复算通过，两个独立基线研究者均完成了预定辨别。它们验证了这组校准工具，也暴露了固定查询菜单的上限；当前保持基线不变，继续准备更开放的编码研究，不据此宣称方法提升。

下一项编码研究固定 EEGMAT 的一个属性组，让研究者自己编写线性与灵活读出，检验固定干预后的恢复能力。缓存准备、数据对应检查和代码接入已完成；独立研究者尚未运行。这是主助手设计的改编实验。论文自动制题与完整报告比较的统一入口正在另行补齐，不能用该任务的执行基础代替。

第一项方法迁移研究已完成真实源任务、一次方法更新和三条件各两次目标Actor运行。六次有效覆盖均为Q1 `24/24`、Q2 `0/2`、Q3 `0/2`；后两项未执行，方法组没有覆盖增益。
