# EEG 预测情绪评分：把"同一人的状态变化"与"不同人的稳定差异"分开

## 0. 结论先行
现有材料能支持一个明确的判断：**"EEG 能预测情绪评分"这句话在现有证据格式下是不可识别的**。因为评分与 EEG 的协变至少可以走三条通道——(i) 人内瞬时状态耦合，(ii) 人与人之间的稳定水平差异（被试身份），(iii) 场次/日的非平稳偏移（既非稳定特质、也非瞬时情绪）——而绝大多数公开数据只在一个场次内采一次，三条通道在设计上纠缠在一起。要区分它们，**最小可行方案不是换更好的解码器，而是"多人 × 多场次 × 同一刺激集 + 人对自身做基线标定"的方差分解设计**。

## 1. 可操作定义

设被试 i 在场次 s 的第 t 个试次：自评分为 y_ist，EEG 特征为 x_ist。写成分量模型

- y_ist = μ + b_i + c_is + e_ist
- x_ist = μ_x + u_i + w_is + v_ist

操作定义（不是哲学定义）：

- **同一个人内的状态变化**：s_ist := y_ist − b_i − c_is，即去掉该人跨全部场次的均值 b_i、再去掉该场次的均值 c_is 之后的试次级偏差。"人能预测自己的状态"= 用 v_ist 预测 s_ist。
- **不同人之间的稳定差异**：b_i（以及 u_i 与 b_i 的关联）。"EEG 携带稳定个体差异"= 用留一被试（leave-one-person-out）预测 b_i。
- **场次偏移**：c_is / w_is。它**必须被显式建模**，否则会被误算进上面二者之一。
- 关键结构性质：**b_i 只有 N_person 个观测值**，而 s_ist 有 N_person×N_session×N_trial 个。因此"稳定差异"这一支永远是统计上更贵、更容易假阳/假阴的一支。

## 2. 为什么现有证据无法区分（三条混淆通道）

1) **被试身份在特征空间里极其显眼，但它不等于情绪信息。** 该文在 DEAP/MAHNOB/DREAMER 上的 t-SNE 图上，样本按被试而非按情绪标签聚集，作者据此判断"被试对 EEG 的贡献明显高于情绪"[ev_74eaf4bc0082]。更硬的结果是：z-score 标准化的跨被试模型在多数情形下贴着 50%（DEAP 效价 0.50、MAHNOB 0.52–0.56、DREAMER 0.50–0.52），而同一批数据的被试内模型为 0.54–0.66；用被试自身中位数二值化做"个人化归一"后，跨被试准确率升到 0.51–0.65（如 MAHNOB 径向 SVM 效价 0.56→0.65，唤醒 0.52→0.61）[ev_74eaf4bc0082]。
   - 我的推断（非原文主张）：该文对每类每被试随机抽取等量样本（DEAP 效价 24 人×32 样本等），这**恰好把"b_i 的类间偏移"归零**——即每人正负类各半。所以它贴 50% 的结果说明"跨人共享的刺激锁定模式"很弱，但**并不能**说明"身份通道无法承载情绪信息"。恰恰相反，它说明的是：一旦把个人的类均值拉平，跨人泛化就塌了。这正是一个需要被显式区分的识别性问题。
2) **同一人的情绪相关 EEG 模式跨天不稳。** 8 天、10 人、30 导的 ICA 研究显示：源的数量与位置、以及其对效价/唤醒的频谱调制都在变；九簇平均跨天可复现率 76.03±10.40%，跨被试共有性 71.11±18.33%；按"≥6/8 天"标准，只有约 2–4 名被试表现出对某一二值状态一致的时空频谱倾向（效价：中央中线 beta 4/10；唤醒：上顶 beta 仅 2/8 = 25%）；代表性的单人分析中相关系数只有 r=0.26、0.25、0.16、−0.21 [ev_d3f89ccca87f]。→ 人内"状态—EEG"映射是**场次依赖**的，单次录制的被试内准确率不能当作稳定特质读数的证据。
3) **单场次大样本也无法分离。** FACED 有 123 人、32 导、28 段 30 s 视频、9 类情绪，DE+SVM 在 1 s 尺度上得到被试内 78.8±1.0% 与跨被试 69.3±1.5%（正/负二分类）[ev_6619560afa7e]。这个约 9.5 个百分点的落差常被读作"个体差异"证据；但**我的推断**：该评估是在同一场次内、对同一批视频的 1 s 相邻 epoch 做十折交叉，训练与测试 epoch 来自同一试次/同一视频，时间泄漏与被试身份都无法排除，且"跨被试折"仍然共享同一段录制条件。因此它既不能证明稳定特质，也不能证明状态耦合。
- 对照设计上可借鉴的模板：一份 60 人、3 场次（90 min 内短期 + 间隔一个月长期）、静息与自主认知状态的 test-retest 数据集，把行为量表作为稳定量报告——SAS 焦虑 t(57)=−1.38, p=0.17；SDS 抑郁 t(57)=−1.56, p=0.12；ESS 嗜睡 t(57)=−1.11, p=0.27；PANAS 正/负性 F=0.72, p=0.49 / F=1.57, p=0.21，一个月内均未变；而思维漫游（ARSQ）在人与场次间方差都很大，且有维度（planning、verbal thought）跨场次改变 [ev_fad98f5a28bb]。这正是"稳定量 vs 波动量"可操作化的现成范式，**但它不含情绪诱发，也不是我的实验**。

## 3. 竞争解释与各自需要的证据

**H1 状态耦合（readout）**：人内试次级 EEG 波动反映瞬时情绪；身份不提供额外信息。
需要的证据：人去均值+去场次均值后的特征能跨场次预测 s_ist；每个被试的斜率符号一致；控制场次均值与 KSS/阻抗后效应仍存。现有材料：仅有弱支持——单人源水平相关 |r|≈0.16–0.26 [ev_d3f89ccca87f]，以及 FACED 中被试内跨 28 段视频的功率—评分相关 [ev_6619560afa7e]；两者都未做跨场次留出。

**H2 特质/身份中介**：预测力来自"认出这是谁 → 猜他的平均评分水平"；EEG 的个体差异是稳定特质（基线 alpha/beta、皮层兴奋性）并与评分风格/基线情感共变。
需要的证据：留一被试的 u_i → b_i 预测显著；人去均值后解码塌到机会水平；被试 ID 可解码性高**且**与 b_i 相关。现有材料：只有间接支持（被试聚集结构、个人化归一的有效性）[ev_74eaf4bc0082]；无任何留一被试的特质预测报告。

**H3 场次非平稳（第三种成分）**：耦合真实，但映射每场次被重新参数化；跨场次"状态"信号主要被场次偏移（电极重贴、阻抗、警觉度）吞掉。
需要的证据：场内预测好、跨场次同人迁移≈机会、但用本场次 2 min 基线做标定即可恢复；场次 ID 在人内高度可解码；场次偏移与 KSS/阻抗相关。现有材料：源与频段调制跨天改变、可复现率 76%、仅少数人一致 [ev_d3f89ccca87f]，与"需要每人/每场次标定"一致；test-retest 范式提供了估计该成分的工具 [ev_fad98f5a28bb]，但我读到的部分没有报告 EEG 的 ICC 数值。

**H0（必须预留的第四解释）**：特征信噪比不足，三条通道都≈0。此时"不可区分"不是设计缺陷，而是功效不足。

## 4. 最小实验（提案，非已完成的 EEG 实验）

**数据/被试**：40 名健康成人（特质臂是约束项；40 人对 r≈0.4 的留一被试相关仅约勉强够用，需按此下限规划而非上限）。32 导、500 Hz（或 250 Hz），EOG 同步。

**设计**：每人 **3 个场次**（D1、D4±2、D22±3；固定时段 ±1 h）。为什么是 3 而非 2：两次场次的差值无法把"稳定偏移"与"当日偏移"分开，三次才能同时估计 b_i、c_is 与残差。每场次：2 min 睁眼 + 2 min 闭眼静息（**场内标定用**）→ 24 个 30 s 情绪视频试次（16 段为跨场次固定、8 段为每场次新片），每试次后效价/唤醒 1–9 评分；块间插入算术任务以阻断延续效应（FACED 的范式做法）[ev_6619560afa7e]；每场次记录 KSS、PANAS、电极阻抗、室温。

**对照（缺一不可）**：
- 被试内标签置换零分布（保留人被试结构，破坏试次—标签配对）；
- **被试 ID 解码**控制：能否从特征判断"这是谁"（预期很高——只有高，才说明必须把人内去均值做实）；
- **场次 ID 解码**控制（人内）：若人内场次可解码性高，说明存在非情绪漂移；
- 刺激控制：16 段固定片消除"刺激身份"与"人/场次"的混淆；8 段新片检验刺激泛化；
- 干扰回归：EOG、阻抗、KSS；
- 所有"个人化归一"（如被试中位数二值化 [ev_74eaf4bc0082]）**只在训练折内拟合**，避免把测试试次的信息泄漏进变换。

**主要可观测量**：预注册的单一主终点 r_state = 留出场次（场次 3）× 留出试次上，预测的去均值评分偏差 ŝ 与真实 s 的相关；配套预注册的次终点 r_trait = 留一被试的 u_i 与 b_i 的相关；以及评分与特征的方差分量（σ²_person / σ²_session / σ²_trial）。

**各解释下的预测**：
- H1：r_state ≥ 0.15 且置信区间不含 0，跨场次成立、并对新片有泛化；r_trait ≈ 0；**而被试 ID 解码高**（身份在，但与评分水平无关）——这个"高身份可解码 + 低特质预测"的组合是 H1 最锐利的签名。
- H2：r_trait 显著（如 ≥0.4，留一被试）；人内去均值后 r_state ≈ 0；被试 ID 可解码性高且与 b_i 正相关。
- H3：场内 r_state ≥ 0.15，但跨场次 ≈ 0；仅用本场次 2 min 基线标定后恢复；场次 ID 人内可解码性高，且场次偏移与阻抗/KSS 相关。
- H0：三者皆 ≈ 0，而朴素池化模型（原始特征→原始评分）仍有较高"准确率"，则说明该类特征的天花板问题，且池化准确率是虚假的。

**反证条件**：若人内、场内 r_state 也≈0，而池化模型明显高于机会水平，则本方案的 H1/H2/H3 同时被否证，"EED 预测评分"在 PSD 类特征上的既有报告应被重新解释为身份/场次泄漏——这是一个有价值的强负结果，而非失败。

## 5. 即使做完仍无法区分（必须写明）

1. **"特质"是情感特质还是评分/标签使用特质。** 稳定个体差异可能是"某些人习惯打高分、且基线 EEG 不同"，而非"情感体验水平不同"。没有独立于自评的状态测量（行为、生理），这个替代解释永远无法被排除；b_i 的定义本身依赖自评。
2. **人内耦合的情绪特异性。** 去掉场次均值后，场内疲劳/努力/注意漂移仍会同时推动 alpha-beta 与评分，从而伪造"状态耦合"。等唤醒、等注意的情绪对照只能削弱而不能清除这一项。
3. **场次偏移的来源。** 真正的慢变心境（mood）与电极重贴/阻抗/皮温等测量性非平稳都会产生场次偏移；二者在纯 EEG+自评数据中等价，需要重新贴帽对照或同步外周生理才能分开。
4. **时间尺度相对性。** "状态 vs 特质"不是二分而是给定窗口下的方差划分：3 周内稳定的偏移可能只是一个慢变状态（心境 episode），而一个月的 retest 也只能给"特质"一个上界 [ev_fad98f5a28bb]。任何"稳定差异"结论都只在该窗口内成立。
5. **因果方向**：本设计只做预测与分解，不操纵 EEG，无法区分"EEG 是情绪的读出"与"共同第三因驱动二者"。
