# 从"EEG 预测情绪评分"中分离个体内状态变化与个体间稳定差异：一个最小判别实验

## 1. 识别问题（这是我的推理，非文献结果）

设被试 *i* 在试次 *j* 的评分为 y_ij、EEG 特征为 f_ij。一个把所有人数据混在一起训练的"跨被试解码器"报告的准确率/相关，混合了两种完全不同的方差来源：同一人跨试次的波动，和人与人之间稳定的水平差。只要"评分整体偏高的人"同时也具有某种稳定的 EEG 特征（alpha/beta 基线功率、通道阻抗、脑结构导致的场分布等），解码器就可以靠"认出是谁"来"预测评分"，而完全不追踪情绪变化。因此**单次会话、跨被试池化的高准确率对状态假设不构成证据**。文献中恰好有两种相反的表面征象：EEG 样本在 t-SNE 中按被试而非情绪聚簇，被试对信号的贡献明显大于情绪[ev_74eaf4bc0082]；但同一批作者发现"去掉被试相关成分"的被试内基线归一化能把跨被试准确率从接近 50% 提升到约 0.54–0.65（DEAP 价态，p<0.01–0.02，Friedman 检验）[ev_74eaf4bc0082]。这说明个体稳定成分既可能"泄漏"进预测，也可能"淹没"掉可共享的状态信号——两者都需要显式的方差分解才能分辨。

## 2. 操作定义

**个体内状态变化（within-person state）**：以人为单位对试次做中心化后的协变。
r_within = corr( y_ij − ȳ_i , f_ij − f̄_i )，且在**留出的另一次会话**上做外样本评估；即"当这个人此刻比平时打分高时，其 EEG 是否也偏离他自己的基线"。

**个体间稳定差异（between-person trait）**：两层同时满足。
(a) 人水平均值可跨人预测：ȳ_i 与 f̄_i 的相关 r_between；
(b) 时间稳定性：同一 f̄_i 在**约 1 个月间隔**的重测中 ICC/重测相关显著高于 0（可参照已有 test-retest 设计：60 名被试、3 次会话、90 分钟内短期与 1 个月长期重测、含静息与任务态、并同步采集睡眠/情绪/心理健康/走神等行为量表）[ev_fad98f5a28bb]。
若 (b) 不成立，则"稳定差异"这个构念本身在该特征上不成立，剩下的只能叫"会话特异偏移"。

## 3. 竞争解释

**E1 身份/偏移泄漏（"是谁"而非"怎么了"）**：池化预测主要由稳定个体差携带。需要的证据：r_between 大而 r_within≈0；用"只给每人一个常数预测"的模型即可复现池化准确率；对同一特征做被试身份分类远高于机会水平。文献支持其可能性：被试效应 > 情绪效应，池化模型在 z-score 下接近 50%[ev_74eaf4bc0082]，说明个体偏移足以支配信号空间。文献中还有一个反向警示：早期"跨被试高准确率"可能部分来自类别不平衡（如 56–44%、61–39%）[ev_74eaf4bc0082]，所以任何池化指标必须先在被试内配平。

**E2 可共享的状态编码**：存在跨人同向的、随情绪波动的 EEG 模式。需要的证据：r_within 显著、符号跨人一致、在个体中心化后仍能跨人被试泛化。文献对 E2 是**部分不利**的：8 天音乐 listening（10 人、30 通道、跨约 2 个月）中，只有 2–4 名被试表现出 >6 天的相对日稳定时空谱倾向；价态的跨人共性约 30–40%，唤醒仅 25%（8 人中 2 人）[ev_d3f89ccca87f]。因此 E2 若成立，应预期"少数人稳定、多数人不稳定"，而不是普遍共享。

**E3 时段漂移混杂（occasion/drift）**：r_within 真实存在，但由会话内缓慢漂移（觉醒、疲劳、睡眠、阻抗、注意）同时抬高 EEG 与评分造成，而非情绪诱发反应。需要的证据：刺激前基线单独即可预测评分；把会话水平均值回归掉后 r_within 消失；效应随会话内时间单调变化。文献支持这一竞争项的现实性：跨日非平稳性体现在源的数量、位置及其频谱调制上[ev_d3f89ccca87f]；并且作者明确指出，睡眠、情绪、心理健康、自发思维内容等会增大"与电生理因素无关的会话间方差"[ev_fad98f5a28bb]。

## 4. 最小实验（**提案，未执行**；本工作区无真实 EEG 数据）

**数据/样本**：36 名被试（为在 n=36 下检测 r_between≈0.45 保留余量），32 导联，250 Hz。每人 3 次会话：S1 与 S2 同日间隔 90 分钟（短期重测），S3 约 1 个月后（长期重测）——时间结构直接借鉴已有 test-retest 方案[ev_fad98f5a28bb]。

**任务**：每会话 60 个情绪诱发试次（固定刺激集，**每个刺激呈现给每位被试**），每试次后 12 项评分中的核心两项（价态/唤醒，0–7 连续量表，参照 FACED 的试次结构：注视 5 s → 片段 → 评分 → ≥30 s 休息，同价态成块并用算术题隔断以抑制前一情绪残留）[ev_6619560afa7e]；另加 6 个重复出现的锚定试次（会话首尾各 3 个）以估计会话内漂移。每会话前后各 3 分钟睁眼/闭眼静息，用于个体基线与稳定特征估计。

**关键设计要素**（缺一不可）：
1. 每位被试 ≥60 试次，使个体内方差可估；
2. 刺激跨人被试完全交叉，把"刺激内容"作为随机效应从个体差异中分离；
3. 同一人跨会话重测，使"稳定"= 1 个月后仍保留，而不是"本次会话内的常数"；
4. 每次会话重算个人基线（不用跨会话全局基线），避免用未来信息做归一化。

**对照（四项）**：
- C1 个体中心化（减去该人该会话的 f̄ 与 ȳ）→ 去掉稳定成分；
- C2 会话中心化 → 去掉 E3 的漂移；
- C3 刺激前 2 s 基线回归 → 直接吸收预期/漂移状态；
- C4 **被试内标签置换（核心判别对照）**：在每个被试内部打乱试次—评分配对，保持每人的评分均值不变。这样保留了"人可以由均值识别"的全部可利用结构、但摧毁了试次级配对。用置换后的表现刻画"身份可解释的地板"。

**主要观测量**：外样本（留一会话、留一被试）试次水平评分的增量 R²，来自三个嵌套模型：仅人均值项、仅个体内中心化项、两者合并（线性混合模型：y_ij = β0 + b_i + β_w(f_ij − f̄_i) + β_b f̄_i + 会话项）。同时报告 r_within、r_between，以及同一特征集上的被试身份分类准确率与 f̄ 的 1 个月重测 ICC。

**预期结果**

| | r_between | r_within（外样本） | 身份分类 | 置换地板(C4) | 1 个月 ICC |
|---|---|---|---|---|---|
| E1 身份泄漏 | 大（≈0.5+） | ≈0 | 远高于机会 | ≈ 真实表现 | 高 |
| E2 共享状态码 | 可有可无 | 显著，≥70% 被试同向 | 高但不影响中心化后预测 | 明显低于真实表现 | 中等 |
| E3 时段漂移 | 弱 | 会话内显著、跨会话不复现 | 中 | 接近真实表现 | 低（月级） |

**反证条件（falsifier）**：
- 若真实表现与 C4 置换地板之差的可信区间包含 0 → E2 被否证：池化"预测"可完全由个体稳定差解释，任何"EEG 追踪情绪变化"的主张不成立；
- 若 f̄ 的 1 个月 ICC < 0.5 → "稳定个体差异"构念在该特征上失效，E1 亦无法检验（此时唯一可说的是会话特异效应）；
- 若 r_within 在 C2/C3 后消失而刺激前基线单独预测评分显著 → E2 被 E3 取代；
- 若三者皆零 → 在该特征分辨率上"EEG 预测评分"整体不成立（这本身是明确结论）。

## 5. 做完仍无法区分的解释

1. **稳定成分的性质**：r_between 可以由"情绪特质（如特质唤醒/价态基线）"产生，也可以由纯非情绪因素（颅骨厚度、皮层折叠、alpha 峰频、阻抗、帽位）叠加"量表使用习惯/锚点偏移（response bias）"产生。二者给出完全相同的 r_between，观测设计无法仲裁，需要外部操纵（如生理校准 + 量表锚点重训练）。
2. **个体内协变的共同原因**：评分与 EEG 的试次内协变可能是共同第三变量（注意、唤醒、努力、显著性）驱动，而非"情绪本身"。E2 与"注意/唤醒伴随物"在纯观测数据中不可分辨。
3. **特质 vs 极慢状态**：任何有限重测间隔都无法把"稳定特质"与"时间常数很长的状态"（季节、生活压力、慢性睡眠债）分开；严格说特质=时间常数趋于无穷的状态，只能靠间隔长度操作化。
4. **状态×特质交互**：个体中心化会把"高特质者反应更强"这类交互项吸收进个体内项，中心化后的 β_w 不能唯一解释为"纯粹的状态效应"。
