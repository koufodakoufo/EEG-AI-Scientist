# 从「EEG 预测情绪评分」中分离个体内状态变化与个体间稳定差异：一个最小可判别实验

> 说明：以下是**研究提案**，不是已完成的 EEG 实验。材料包中的数字均来自我对所注册文献正文的片段阅读（见文末读取范围与抽取限制）。

## 1. 先把问题变成可识别的问题

设观测 *i* = (被试 *s*, 会话 *t*, 试次 *k*)。*y* 为试次后自评（valence / arousal），*x* 为 EEG 特征（分频段功率，可选连通性）。把评分分解为三层：

```
y_i = μ + b_s + c_t(s) + w_i
```

- *b_s*：被试层均值偏移（跨会话、跨试次平均）→ 对应「**不同人的稳定差异**」；
- *c_t(s)*：会话层偏移（睡眠、时相、电极阻抗、一般唤醒水平）→ 情绪无关的状态漂移；
- *w_i*：试次级个体内偏离 → 对应「**同一个人的状态变化**」。

**可操作定义 A（个体内状态变化）**：存在映射 *f*，使 *w_i* 可由 *x_i* 的个体内偏离（*x* − x̄_s，并控制会话固定效应）预测，且该映射在**留出的另一个会话**中仍然成立。操作化指标：β_w ≠ 0 且跨会话可迁移。
**可操作定义 B（个体间稳定差异）**：被试层 EEG 量 *m_s*（跨会话平均，或**无情绪内容的静息基线**）能预测 *b_s*，且 *m_s* 本身时间稳定（跨会话 ICC 高）。操作化指标：去衰减后的 between-person 相关 + *m_s* 的 ICC。

关键识别性论点（本提案的核心）：单会话 + 跨被试交叉验证下，*b_s*、*c_t* 与情绪标签**完全混杂**，一个预测准确率无法区分二者。这正是现有文献的结构性局限：FACED 报告二分类（正/负）个体内 78.8 ± 1.0%、跨被试 69.3 ± 1.5% 的性能下降 [ev_6619560afa7e]，但这个落差同时可由「个体内映射存在」、「被试身份主导特征」、「日间漂移」三者中的任一个解释。M3D 同时设置了 cross-subject single-session 与 cross-subject cross-session 两种协议 [ev_580a39dd545d]，说明领域已意识到「人」与「日」两个轴，但把它们当作域适应问题而非状态/特质识别问题——这一点是我的推断。

## 2. 材料包给出的约束性事实（文献观测）

1. **被试效应大于情绪效应**：在 DEAP / MAHNOB / DREAMER 上，t-SNE 图中样本按**被试**而非情绪标签聚类；z-score 归一化的跨被试分类接近机会水平（0.50–0.57），个体内模型在 DEAP valence 上为 0.62/0.64，提出的「被试基线归一化」把跨被试提高到 0.54–0.65 [ev_74eaf4bc0082]。该文还提醒：部分跨被试"正结果"可能来自类别不平衡（arousal 56–44%、valence 61–39%）[ev_74eaf4bc0082]。→ 直接支持「个体间稳定差异在特征空间中占主导」。
2. **个体内本身非平稳**：10 名被试、8 天（约跨 2 个月）、80 个会话的音乐聆听实验中，ICA 源的数量、位置与谱调制在日间变化；**不到一半被试（2–4 名）**表现出源复现 >6 天的日稳定倾向；引述的前人结果称同一情绪跨日比同日不同情绪更分散 [ev_d3f89ccca87f]。→ 个体内的"状态"本身带一个与情绪无关的日级漂移层 *c_t*。
3. **可复用的最小设计模板**：60 名被试、3 次会话、短程（90 分钟内）与长程（1 个月）重测，静息（睁眼/闭眼）+ 三种被试驱动认知态，并配睡眠、情绪、心理健康、走神的自评量表 [ev_fad98f5a28bb]。→ 说明「短程+长程重测 + 行为协变量」在公开数据中是可实现的。
4. **密集个体内评分可行**：约 150 小时、114 名被试的音乐聆听数据，含聆听过程中"感受变化"的自报与同步 EEG/ECG/GSR [ev_97eaa43a3d81]。
5. **大样本跨被试基准**：123 名被试、28 个片段、9 类情绪、32 通道、30 s 试次 [ev_6619560afa7e]。

## 3. 三个竞争解释及其所需证据

| 解释 | 主张 | 需要的证据 | 现有材料的态度 |
|---|---|---|---|
| **H1 状态信号说** | EEG 主要编码个体内情绪波动；跨被试可预测性只是同一映射的聚合 | 控制个体均值与会话效应后 β_w 显著且跨会话迁移；β_w ≈ β_b | 未被现有材料排除；但跨被试接近机会的结果构成**弱反对**（若无被试归一化，H1 预测跨被试应保留部分可迁移性）[ev_74eaf4bc0082] |
| **H2 特质/身份混杂说** | EEG 主要编码稳定个体属性（alpha 峰频、基线功率、解剖常量、评分风格）；"预测评分"实为"识别是谁" | β_w ≈ 0；身份解码很高；**静息基线**（无情绪内容）即可预测 *b_s*；*m_s* 跨月 ICC 高 | 获得 74eaf4bc0082 的强支持（被试聚类、跨被试近机会）；但该文同时显示被试归一化后仍有 0.54–0.65 的可预测性，说明**并非全然是身份** |
| **H3 非平稳映射说** | 映射本身漂移；所谓"稳定差异"只是慢漂移的一次快照 | β_w 在同日 S1→S2 存在、跨月 S1→S3 消失；*m_s* 跨月 ICC 低；源/谱特征会话间不稳定 | 获得 d3f89ccca87f 支持（仅 2–4/10 被试源可复现 >6 天）；但与 FACED 个体内 78.8% 的高性能存在张力（后者为同日、单会话内）[ev_6619560afa7e] |

三者并不互斥；本实验要判定的不是"哪个对"，而是**各层方差各占多少、映射是否跨层同构**。

## 4. 最小实验

**数据/被试**：N = 40（性别平衡，本科/研究生年龄段以压缩年龄带来的解剖差异，参照 [ev_fad98f5a28bb]）。每人 **3 次会话**：S1 与 S2 **同日、间隔 ≥90 min**（短程重测）；S3 间隔 **2–4 周**（长程重测）。32 通道湿电极，250 Hz。

**每次会话**：① 3 min 睁眼 + 3 min 闭眼静息（**trait 探针，无情绪内容**）；② 30 个 60 s 情绪诱发片段（9 类情绪平衡 + 中性，覆盖 valence/arousal 四象限），每片段后 valence、arousal、familiarity 自评（1–9）；③ 记录睡眠、咖啡因、时相、简版当前心境。

**关键设计操纵**：片段顺序在每次会话内**独立随机化**，使试次级状态变异与被试、刺激解耦；其中 10 个片段在三个会话**重复出现**（检验刺激特异反应稳定性），其余 20 个每次不同。三个会话分别测，才使 *b_s*、*c_t*、*w_i* 可分别估计。

**对照（五项，均事先注册）**
- **C1 个体内中心化 + 会话固定效应**：所有预测量在个体内（并进一步在会话内）去均值。
- **C2 双置换零分布**：① *个体内置换*（打乱同一人的试次—评分配对，保留每人均值）→ H1 的零假设；② *个体间置换*（保留个体内序列，打乱"人—特征"对应）→ H2 的零假设。二者给出 ΔR²_within 与 ΔR²_between 的可比零基线。
- **C3 身份解码对照**：同一特征预测 40 类被试身份的准确率。若身份高度可解而个体内情绪不可解 → 支持 H2。
- **C4 静息基线探针**：仅用静息特征预测 *b_s*，检验"预测情绪"是否其实是"预测稳定个体差异/评分风格"。
- **C5 伪迹控制**：EOG/EMG 参考通道跑同一 pipeline，检验"预测"是否来自与评分共变的伪迹；监控阻抗与头动随会话漂移（ICA 去眼电的做法与 FACED 一致 [ev_6619560afa7e]）。

**主要可观测量（单一）**：**ΔR²_within^out** —— 以 S1+S2 拟合、在**留出的 S3** 上评估的、对 (y − ȳ_s − ĉ_t) 的样本外增量解释力；基线模型含被试截距、会话截距、刺激类别。判别性比较量（同一报告内）为 **β_w − β_b** 的 bootstrap 置信区间。（预先说明：仅靠个体内 R² 无法判别，必须与 β_b 同报告。）

**预期结果与预注册判据**
- **H1 成立**：ΔR²_within^out > 0（95% CI 排除 0），S1→S3 保持，且 β_w − β_b 的 CI 包含 0（同一映射在两层通用）；C4 静息探针基本失效。
- **H2 成立**：ΔR²_within^out ≈ 0 而 C3 身份解码远高于机会，*m_s* 跨月 ICC ≥ 0.6 且 C4 可预测 *b_s*。结论将是："EEG 预测情绪评分"是关于**人**的陈述（特质/反应风格），不是关于**时刻**的陈述。
- **H3 成立**：ΔR²_within 在 S1→S2 存在、S1→S3 坍塌至零分布内；*m_s* 跨月 ICC < 0.4；源/谱特征会话间不稳定（可对照 [ev_d3f89ccca87f] 的复现率）。此时"稳定差异"本身也只是慢状态快照。

**反证条件（falsifiers，明确可被数据推翻）**
- 反驳 H1：ΔR²_within^out ≤ 0（CI 上界 < 0.01）且落在个体内置换零分布内，或 S1→S3 迁移为机会水平。
- 反驳 H2（强版本）：存在显著的、控制个体与会话固定效应后的 β_w，且跨月复制，同时 β_w − β_b 的 CI 包含 0，而 C4 静息探针不能预测 *b_s*。
- 反驳 H3：β_w 跨月保持且 *m_s* 一月 ICC ≥ 0.6（映射与个体量都稳定）。
- 反驳本设计的整体有效性：C5 显示预测主要来自 EOG/EMG 通道（则所有"预测"结论作废）。

**为什么这已是最小**：单会话无法把 *c_t* 与 *b_s* 分开；无重复片段无法排除刺激特异反应冒充"状态"；少于 3 次会话无法把"稳定"与"慢漂移"在同一被试内区分；无静息探针无法检验 H2 的"无情绪内容"预测。

## 5. 即使做完实验仍无法区分

1. **情绪特异性 vs 一般过程**：评分与唤醒、注意、努力、疲劳、眼动/呼吸共变；观测性 EEG + 自评无法把"情绪编码"与"一般唤醒/负荷编码"分开，需操纵或干预（本设计不含）。
2. **稳定差异的"内容"**：H2 成立也只说明"存在时间不变的 EEG 偏移与个体均值评分相关"。它可能是情感特质、也可能是 alpha 峰频/颅骨厚度/基线唤醒、也可能是**评分量表使用风格**——三者在"时间不变"这一点上等价。
3. **真特质 vs 长于重测间隔的慢漂移**：trait 与 slow-state 的界线由重测间隔界定，不由数据内部决定；1 个月 ICC 高并不证明"永久"。
4. **因果方向**（EEG→状态 还是 状态/外周反馈→EEG）：无操纵则不可判定。
5. **通用编码 vs 每人各异但各自稳定的编码**：N = 40 只能检验"可跨人迁移的平均映射"；每人内部稳定、彼此不同的映射与共享编码在聚合后可能产生相似结果。
