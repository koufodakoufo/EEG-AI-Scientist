先说明前提：表中百分数若默认是准确率，且缺少试次数/窗口数、类别分布、交叉验证折数、重复随机种子、置信区间和切分实现，那么下面只能做方法学解读，不能做强统计推断。若为平衡二分类，机会水平约为 50%；若不是二分类或类别不平衡，不能直接把 50% 当机会水平。

## 1. 哪些数值变了？变化多大？

- **window 切分**：原标签 **99.3%** → 试次级随机标签 **99.2%**，变化 **-0.1 个百分点**。基本不变。
- **trial 切分**：原标签 **49.6%** → 试次级随机标签 **50.8%**，变化 **+1.2 个百分点**，是轻微上升，不是下降；两者都在 50% 附近。
- **window 与 trial 的差距**：原标签下为 **99.3% - 49.6% = 49.7 个百分点**；随机标签下为 **99.2% - 50.8% = 48.4 个百分点**。大差距仍然存在。
- 若假设平衡二分类，则 trial 原标签 **49.6%** 比 50% 低 **0.4 个百分点**，trial 随机标签 **50.8%** 比 50% 高 **0.8 个百分点**；但不知道重复切分/随机种子波动，不能判断这 0.8 或 1.2 个百分点是否有意义。

## 2. 能否说“随机化使 trial 切分从高水平降到机会水平”？

**不能。**

理由是：

- trial 切分的原标签结果本身只有 **49.6%**，已经接近 50%，不是“高水平”。
- 随机标签后是 **50.8%**，比原标签还高 **1.2 个百分点**，不是下降。
- 真正的高水平是 window 切分的 **99.3%** 和随机后的 **99.2%**。把 **99.3%** 与 trial 的 **49.6%** 比较，是在同时改变“切分方式”和“标签是否随机化”，不能归因于随机化。
- 因此可以说的是：**trial 切分在原标签和随机标签下都接近 50%**；**window 切分在原标签和随机标签下都很高**。不能说是随机化把 trial 切分从高降到机会。

## 3. 这些数字支持/不支持什么结论？

### 支持“window 切分存在试次/窗口级泄漏或非语义依赖”

window 切分下，原标签 **99.3%**，试次级随机标签仍为 **99.2%**。随机化是在试次层级做的，同一试次所有窗口共享新标签；而 window 切分允许同一试次窗口同时出现在训练和测试侧。分类器即使没有学到原标签语义，也可能通过“试次指纹”——例如重叠窗口、邻近时间窗、试次内自相关、同一试次的特异噪声/状态——把随机标签映射到测试窗口。**99.2%** 的随机标签性能是很有力的泄漏信号：它说明在这个切分下，高性能不需要原标签语义也能达到。

但要注意：这支持“window 切分不能解释为对未见试次的语义泛化”，**不能精确区分**泄漏到底来自完全重复窗口、相邻窗口、试次内时间相关，还是其他试次级特征。

### 不支持“任务存在强语义泛化”

trial 切分原标签 **49.6%** 没有显示高于 50% 的泛化能力。因此这些数字**不支持**“分类器能泛化到未见试次并学到强语义”。window 的 **99.3%** 也不能拿来支持语义泛化，因为随机标签下仍有 **99.2%**。

### 但也不能据此断言“没有语义信号”

trial 的 **49.6%** 和随机后的 **50.8%** 都接近 50%，这可能意味着没有可泛化信号，也可能意味着试次数少、会话漂移、标签噪声、预处理/模型不适配，导致真实弱信号被淹没。没有置信区间和功效分析时，不能把 **49.6%** 解释成“证明不存在语义信息”。

### 会话/被试因素：目前不能下结论

这些数字没有说明 trial 切分是否按 session/subject 分组。即使 trial 切分，如果同一被试/会话仍在训练和测试两侧，也不能直接排除会话/被试因素。window 下随机标签仍高，更像试次级指纹泄漏；但不能仅凭表中断言“不是会话/被试因素”。要区分必须做 leave-one-session-out、leave-one-subject-out 等对照。

## 4. 还需要哪些对照？至少两种竞争解释

### 竞争解释 A：window 高值是试次/窗口泄漏

同一试次的窗口跨训练/测试，分类器可通过重叠窗口、时间邻近或试次特异特征记住随机标签。随机标签下 **99.2%** 与这一解释一致。但目前不能区分：完全重复窗口、相邻窗口自相关、试次内状态指纹、其他数据泄漏。

### 竞争解释 B：trial 接近机会是统计功效/漂移/预处理问题，而非无泛化信号

trial 原标签 **49.6%** 可能受试次数少、会话/被试差异、标签噪声、特征/模型不合适影响，置信区间可能包含小幅但真实的泛化效应。需要更多试次、重复交叉验证和置信区间才能判断。

### 竞争解释 C：window 原标签与随机标签只差 0.1 个百分点可能是天花板效应

**99.3%** 与 **99.2%** 差 **0.1 个百分点**，不能简单分解为“99.2% 全是泄漏、0.1% 是语义”。可能泄漏已经接近饱和，原标签的额外语义贡献被天花板掩盖；也可能确实几乎没有额外语义贡献。需要非饱和设置或其他对照。

### 竞争解释 D：trial 随机标签 **50.8%** 的轻微高于 50% 可能只是有限样本噪声

需要重复试次级随机化多次，得到零分布，而不是只看一次随机化。

### 建议补充的证据

- 报告试次数、窗口数、被试/会话数、类别分布、指标定义、折数、重复种子、置信区间。
- 对试次级随机标签重复很多次，给出两个切分下准确率的零分布和 p 值/效应量。
- 检查 window 切分中训练/测试窗口的重复、重叠、时间邻近、同一 trial/run/session/subject 比例；加入时间间隔/embargo，去除重复或近重复窗口。
- 做 leave-one-trial-out、leave-one-session-out、leave-one-subject-out；并把窗口预测聚合到试次级再评估。
- 比较试次级随机标签与窗口级随机标签：若只有试次级随机仍高，说明试次指纹泄漏；若窗口级随机也高，更指向窗口重复/身份泄漏。
- 检查预处理和特征选择是否只在训练折内完成，避免测试信息泄漏。

## 目前不能下的结论

- 不能说“随机化使 trial 切分从高水平降到机会水平”；trial 原标签 **49.6%** 本来就不高，随机后 **50.8%** 还略高。
- 不能说“任务存在强语义泛化”；trial 原标签 **49.6%** 不支持，window 的 **99.3%** 又被随机标签 **99.2%** 严重削弱。
- 也不能说“已经证明不存在语义信号”；缺少功效和置信区间。
- 不能把 window 的 **99.3%** 解释为纯语义性能；随机标签下 **99.2%** 表明其中至少很大一部分可无需原标签语义达到。
- 不能精确归因泄漏来源是窗口重叠、试次内自相关还是会话/被试因素；需要分组切分和重复/邻近窗口检查。
- 不能把 **49.6%**、**50.8%** 直接称作严格“机会水平”，除非确认二分类、类别平衡且置信区间覆盖机会水平。
