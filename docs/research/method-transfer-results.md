# 方法迁移试点结果：真实科研链条完成，未观察到证据覆盖增益

`method-transfer-v1`，2026-11-02。本报告仅总结第一项研究：EEGMAT 来源任务、一次方法更新，以及 EEGMMIDB 上三组各两次独立目标运行。

**六次目标运行均产生了可复核的属性读出证据，但全部止于 Q1；知识加方法组没有比知识组或基础组覆盖更多研究问题。** 六次独立拟合、全部144行测试前向及可信指标重算均通过。结果支持“真实来源经验→冻结方法材料→独立目标运行→审计”这条链已经运行；不支持方法有效性提升、递归自我改进（RSI）或 ignition 已成立。

## 研究了什么，为什么设三组

来源任务是 EEGMAT 心算与背景条件，目标任务是 EEGMMIDB 睁眼与闭眼条件。两者均使用冻结的 CBraMod 骨干、本项目拟合后冻结的任务头，以及12组手工属性、62个数值列，在第6、12层分析。训练、验证、测试各含24、6、6名被试，对应576、144、144个窗口。因此，这次检验的是**跨数据集、同一问题类型的方法迁移**，不是跨研究问题泛化，也不是 BrainPEC 原条件复现。[任务与条件映射](method-transfer-task-map.md)保留了完整边界。

受测 Actor 是实际调用的独立研究者，Builder 负责准备与审计，两者不能混算成果。一个真实来源 episode 使用5次模型会话完成了Q1，未实施干预或残余探针。早先 `r01` 因时间格式解析失败而止于启动准备，实际模型调用和科学作业均为0；`r02` 才是这一次真实来源研究，不能算成两个科研重复。

随后，一次独立 updater 调用只读取白名单中的来源训练/验证开发记录，不读取来源终测答案、目标材料或私有参考，生成12条事实摘要 K 和3条方法规则 M。独立审核确认其来源与边界后原样冻结；这里没有多候选搜索、独立选择集上的经验筛选或目标反馈调优。三条规则分别针对：缓存训练与实际部署的一致性；绝对恢复能力与优于随机对照的区别；完成的实验与报告主张逐项对应。每条均带触发条件和适用边界。

| 条件 | 两次独立运行得到的材料 | 要控制的问题 |
| --- | --- | --- |
| 基础组 `base` | 共同题面、数据和工具 | 原研究者能完成什么 |
| 知识组 `knowledge` | 共同材料＋K | 仅增加来源事实是否有用 |
| 方法组 `method` | 共同材料＋相同K＋M | 方法材料是否在相同知识上增加收益 |

主要对比是 method−knowledge。六次均采用 `gpt-6.1-sol / medium`，独立上下文、相同工具与预算；材料实际注入和模型身份经过运行审计。每次上限6会话、每会话900秒、总90分钟，最多两个科学迭代另加一次基线；实际均用5会话完成。最多两个 episode 并行，科学作业每项4核、4数值线程、无GPU；内存为地址空间限制，磁盘采用采样监测，不宣称具备未实现的 cgroup 限额。

K中的方法来源事实也可能指导行为，且没有等长通用提醒组。即使出现差异，也不能只凭分组名称完全排除知识成分、篇幅或注意力效应。

## 六次运行完成了多少有效证据

本地任务的三个分项是：Q1，属性能否从表示中读出，并与真正重新拟合的随机化目标探针对照；Q2，修改表示后，预测变化是否超过匹配的一般损坏对照；Q3，在修改后的训练表示上重新拟合探针，检查干预后还剩多少可读出信息。

有效证据要求来源审核、实际执行、冻结参数、可信聚合与独立复放同时成立；分数为负也可以是有效证据。按照目标前冻结的[评价规约](method-transfer-evaluation.md)，六次最终结果如下。机器数值覆盖 N 与审计有效覆盖 V 在本次恰好相同。

| 原始运行 | 有效Q1 | 有效Q2 | 有效Q3 | 独立拟合／全测试前向／指标重算 |
| --- | ---: | ---: | ---: | --- |
| base-01 | 24/24 | 0/2 | 0/2 | 全部通过 |
| base-02 | 24/24 | 0/2 | 0/2 | 全部通过 |
| knowledge-01 | 24/24 | 0/2 | 0/2 | 全部通过 |
| knowledge-02 | 24/24 | 0/2 | 0/2 | 全部通过 |
| method-01 | 24/24 | 0/2 | 0/2 | 全部通过 |
| method-02 | 24/24 | 0/2 | 0/2 | 全部通过 |

Q2和Q3均为**未执行**，不是零效应、干预失败或没有信息。六次都为 `q1_only=1`、`numeric_scope_complete=0`。两个重复中，方法组相对知识组的有效覆盖差均为零；这里没有观察到方法材料带来的覆盖增益。它不证明所有方法更新都无效，也不足以排除其他未可靠衡量的行为差异。

独立拟合只使用允许的训练/验证材料，比较了全部保存参数及选择记录；全量前向覆盖每次144行、两层全部真实/随机探针预测，随后复核全部305项释放指标。离散身份与选择精确核对，浮点沿用预定绝对/相对容差各 `1e-5`，没有因结果修改容差。六次测试前向预测在同一冻结运行环境下实际均完全一致。容器和进程清理通过。**前向通过本身不能证明拟合；本次另有单独的拟合复放。** 这也不等于独立重新生成了随机LLM研究轨迹，或验证了所有解释的科学价值。

去除组标签的报告审核保留了小错误：method-01 一项验证区间末位应为0.516445，报告写作0.516446；method-02 一项应为15.287483，写作15.287482，并明确遗漏了同一验证行的三个区间。这些误差未改变符号或科学解释，但没有被复放成功“修好”，原报告保持不变。其余四份报告未发现所核对表格的数值抄录矛盾。部分附属并列命题尚未拆至最细原子，一些行动历史、外部来源和新颖性主张仍受审核材料限制；不把审核记录条数当成已认证的完整主张分母。

## Q1发现说明了什么

六次测试均有20/24个原始R²点估计为正，但只有三项近似家族调整区间整体高于零：第6层 Hjorth mobility，以及第12层 delta、theta 功率。两层 theta–gamma PAC 的家族区间均为负。这支持当前池化表示、属性定义和线性探针下的选择性恢复；既不证明其余属性完全不存在，也不证明分类器依赖这些属性。

“优于对照”与“恢复得好”确实不同。例如 knowledge-01 的第12层 delta–beta PAC 测试R²为−0.392381，但真实探针减随机探针为0.449094，边际95%区间为[0.137213, 0.769393]。随机探针更差，不能把这解释成良好绝对恢复。六次优于对照的边际区间数为17至21，使用了不同随机排列；这个数量不是研究质量分数，也不能直接归因于方法材料。

六次均保留原分类器，测试 balanced accuracy 都是0.638889。该数字描述已有模型，不是本次研究者提高了模型性能。任务内区间按被试重采样，不能把144个窗口当成144名独立被试，更不能用它作为方法组收益的置信区间。

私有当前环境参考在目标运行前冻结，但不是所有 Actor 实现的逐数值答案。参考按属性组和层选正则，Actor按层选择；五次运行的正探针只有11/24个单元实现了相同正则强度，其R²最大绝对差约为 `2.17e-7`。method-01 的目标函数按576个训练样本平均损失，所选0.1等价于求和损失下的57.6，不能直接与其他运行的100/10比大小。随机对照、池化精度和有限bootstrap抽样顺序也有差异。

因此，Actor有三项而参考有两项正家族区间，不构成“超过参考”；第6层 mobility 的正则和区间条件不同，应判为条件不匹配。所有运行24个点估计的正负方向均与当前参考一致，未识别到同条件科学矛盾。历史与当前环境参考的严格前向容差失败仍被保留，没有静默改写为成功；当前参考的独立冻结也不是新增独立样本。

## 与BrainPEC和FIRE怎样比较

BrainPEC的第三个主问题是**属性分类器相对随机特征基线能解释多少FM预测表现，即closure**；本地Q3只是干预后的残余探针。两者不同，本轮均没有产生closure证据。原论文的三种架构、五个任务、63个属性／328列、12层选择，也不同于本轮单一骨干、新任务头、12组／62列和两层分析。

保留 FIRE 启发的问题树与逐主张比较：先判断 Actor 自己的证据是否有效，再分别比较当前参考和论文。以下十二项作者主张的完整出处见[BrainPEC主张索引](brainpec-claim-map.md)及[BrainPEC v2](https://arxiv.org/html/2605.11410v2)。它们是比较目录，不是本轮已复现的结果。

| 论文主张 | 本轮裁决 |
| --- | --- |
| P01：63项属性各自在至少一个模型／任务单元被编码 | 条件不匹配；新任务的选择性恢复不能裁决原15单元的存在性命题 |
| P02：847/945个组合被编码，89.6% | 条件不匹配；分母与判定标准不同，3/24不能与89.6%直接比较 |
| P03：频域族中位探针R²为0.7–0.85 | 条件不匹配；delta/theta结果仅作定性呼应，不能套用数值阈值 |
| P04：编码峰值集中于较浅／中间层 | 未覆盖；两层不足以定位12层峰值 |
| P05：648/945满足作者的模型内干预使用标准，68.6% | 未覆盖；无Actor干预证据 |
| P06：199/945属于encoded-only，21.1% | 未覆盖；没测试使用不等于证实“只编码、不使用” |
| P07：50/63为跨任务、跨架构共同候选 | 未覆盖 |
| P08：频域族主导累计干预效应量 | 未覆盖；读出强不能替代干预贡献 |
| P09：其他五族各在至少四个任务有实质贡献 | 未覆盖 |
| P10：15单元平均closure为0.793 | 未覆盖；没有对应分类器与比值 |
| P11：CBraMod／Stress的closure为0.547 | 未覆盖；任务条件不同且未计算closure |
| P12：三种架构上MDD的closure均高于Stress | 未覆盖 |

本轮提供的是**新条件下编码问题的部分定性一致证据**，没有重发现论文的使用比例、跨任务属性贡献或closure结果。参考的干预成果不能补算成Actor成果。

逐主张规约在目标前冻结，但这份十二项论文索引是在首批目标启动之后补写；它不是事前冻结、经过完整抽取校准的原子集合。因此不计算主张precision／recall／F1，也不发布“官方FIRE分数”。[FIRE](https://firebench.github.io/)比较思路被保留，并不表示本项目已实现其完整评测协议。

## 解释限制与证据入口

每组仅两次、一个目标问题、同一测试划分，不能做方法能力的普遍显著性推断；12组×两层也不是24个独立任务。测试仅六名被试，近似家族区间的极端尾部不稳定；R01/R02眼状态与记录顺序混杂，通道适配及骨干预训练接触仍限制解释。

还有一项实际信息边界缺陷：测试标签数组没有交给候选，但含R01/R02的样本ID可能透露类别。六份候选源码检查未发现据ID构造预测或选择，且全量复放支持其模型计算路径；这不消除元数据暴露本身。不能把“标签文件未挂载”写成“标签绝对不可推知”。该限制如实保留，不事后更换冻结任务或重算评分。
