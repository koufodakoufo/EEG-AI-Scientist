# 旧分类头是否限制了冻结 EEG 表示的表现？

状态：计算前协议。由 Builder 执行的独立 EEG 分析及后续任务准备；不是受测 Agent 的成果，也不是 ignition。正式启动以私有 `ADMISSION.json` 的时间、源码和输入哈希为准。此协议不修改 `method-transfer-v1` 的材料、预算或评分。

## 问题和判断边界

固定一个 EEG 骨干后，手工属性分类器接近其旧分类头，未必表示手工属性已覆盖该表示的预测能力：旧头可能没有充分利用表示。因此，比较旧头、只校准旧分数、新表示读出、手工属性读出和随机输入控制。

这个问题受到 [BrainPEC 的 closure 分析](https://arxiv.org/html/2605.11410v2#S3.SS4) 启发，但数据、特征、分类头和指标均不同。它检验固定读出下的预测充分性；不复现论文原始 closure，也不证明模型在预测时依赖这些属性。

主对比是新表示读出相对旧头的差值。旧头与新读出使用不同训练被试，差异同时可能来自适配、样本差异和训练程序；本实验不把改善唯一归因为某种机制。无改善也不证明表示中缺少信息。

## 数据与固定操作

- EEGMMIDB 的 S037–S072 按 `random.Random(314159)` 打乱，24人训练、6人选参、6人诊断测试。验证：S062/S042/S053/S066/S056/S046；诊断测试：S070/S044/S043/S055/S054/S049。
- S073–S108 的36人为额外确认集；S109不使用。两套测试均在任何新结果出现前确定。主要分析合并42名测试被试，同时报告6人和36人分组结果，后两者仅作描述。
- R01/R02分别为睁眼/闭眼；每次记录只取前60秒，切成12个不重叠5秒窗口。20通道，使用实测FCz，160→200Hz，单位uV/100。沿用现有机械预处理，不按表现排除或替换被试。
- 只读一个共享原始数据镜像，核对官方SHA256清单及每个所选EDF；重复镜像不算额外数据。技术校验失败即停止并保留失败记录。
- 冻结CBraMod骨干及旧EEGMMIDB头。旧头来自S001–S024训练、S025–S030选参，不能当成BrainPEC原始头。精确资源身份在启动前绑定。
- 保存200维表示、62列手工属性、旧头logit和62列独立高斯输入。缓存列顺序为`[0:200] / [200:262] / 262 / [263:325]`。
- 样本及被试使用私有随机nonce生成的不透明ID；各分区独立打乱行。公开训练/验证含标签；封存推理仅含`x/sample_ids/subject_ids`。映射、原始记录名和测试标签不得提供给后续受测研究者。
- 高斯控制以种子271828及不透明样本ID确定，不能从随机输入重建原始类别排列。原始EEG、缓存来源和行映射留在私有审计材料中。

新被试与本次旧36人实验不重叠，但仍来自同一数据集；不能据此保证未进入骨干预训练。R01/R02的眼状态与记录顺序混杂仍在。

## 五个固定读出

| 读出 | 拟合范围 | 用途 |
| --- | --- | --- |
| A：旧头 | 不改变旧logit | 旧模型的实际基准 |
| B：正斜率校准 | 旧分数的正比例系数和截距 | 检查阈值/校准能解释多少差距，保持分数排序 |
| C：新表示读出 | 200维表示上的logistic回归 | 检查固定表示配合新读出的表现 |
| D：手工属性读出 | 62列属性上的logistic回归 | 比较该属性面板的预测充分程度 |
| E：随机输入控制 | 62列高斯输入上的logistic回归 | 与D维度匹配的空对照 |

B–E使用相同24名新训练被试；均只在训练集拟合均值、标准差和参数。各自从`C={0.01,0.1,1,10}`按验证balanced accuracy选参，平分取更小C。无类别加权、属性选择、种子搜索、额外阈值选择或验证集再拟合。默认logit零阈值；最多2000次优化迭代，未收敛即失败。

B在标准化旧分数上拟合，斜率下限为`1e-8`，截距不惩罚；目标与其他读出同为logistic损失总和加系数平方和`/(2C)`。D/E维度相同，C维度不同，不能称容量完全匹配。

所有候选参数和验证分数一起保存；冻结选定参数及输入哈希后，才应用到两套测试。先保存两套无标签逐行预测及哈希，再读取测试真值做评价。测试之后不修改选择。

## 统计与解释

主要指标为balanced accuracy（两类召回率平均）；同时报告AUROC和log loss。每次bootstrap抽取整名被试，保留其全部窗口，各读出共用同一抽样；10,000次，种子161803。

主对比为合并42人上的`C−A`，报告配对95%区间。预定有用差异为0.03 BA，是本次操作性阈值，不是临床阈值。区间下界超过0.03才支持“旧头相对这个新读出存在有用差距”；跨过阈值则证据未定。

次要对比为`B−A、D−A、D−C、D−E`，同时列边际95%区间及四项Bonferroni修正的98.75%区间。多项组合解释使用修正区间：例如只有`D−A`整体落入±0.03、且`D−C`上界低于−0.03，才支持“手工属性接近旧头，却未达到新表示读出”的具体判断。仅未显著不同不算接近或等价。

closure类比值仅为次要诊断：`(D−E)/(A−E)`和`(D−E)/(C−E)`。先报绝对指标、分子和分母。分母配对95%区间下界不超过0.03则标为不稳定；不加epsilon、不截断负值或大于1的值。任一bootstrap比值无定义，则区间不可用，并报告个数。该比值不是因果解释比例。

## 执行、审计与资源

只有原研究六个episode及其科学复放均已结束、容器/进程清理通过后，才部署新增模块并启动本实验。启动前核验旧头谱系、源码/依赖/原始资源及可用磁盘。公开协议、私有准入清单、实际运行日志和失败记录分别保留。
