## 4. 独立真实任务 B 的首选候选

**建议先准备：同一 CBraMod 骨干在另一数据源的左右手运动想象任务中，能否恢复预定运动节律属性；对这些属性的表征干预是否影响新任务头，且超过匹配扰动？** 不预设方向，不要求 Agent 找到某个显著特征。

公开候选是 PhysioNet EEG Motor Movement/Imagery Dataset。官方资料说明它含 64 通道、160 Hz 的真实/想象运动记录和事件注释；同一标签代码的含义随 run 类型变化，因此必须只选定同一种任务并核对 run—事件映射。[官方数据说明](https://physionet.org/content/eegmmidb/1.0.0/)

这提供与心算不同的任务和数据来源，又可复用当前模型接口。它检验的是同一模型家族下的跨数据源/任务迁移，不是跨架构、跨论文泛化；没有匹配论文方法与模型条件时，称“有独立参考的真实研究任务”，不称严格 FIRE-Bench 原论文重发现。

Builder 先完成以下准备，再决定能否本夜进入正式比较：

1. 固定公开版本、可合法使用的文件、被试清单、任务 run、事件语义、排除规则、窗口和通道集合；新下载只进入自有存储。核对 160→200 Hz 的重采样、单位、空间/通道顺序和模型张量契约。原有实验室数据保护规则继续有效。
2. 按参与者冻结 train/validation/test；每个被试的重复 runs 不跨分割。限定窗口数是执行预算，不是按结果挑样本；缺失或坏记录按预先规则处理。
3. 在训练/验证上测一次真实批处理，再决定覆盖层数和窗口规模。候选特征可预定为 C3/C4 附近的 8–13 Hz、13–30 Hz 功率及左右不对称；这是 Builder 的科学切片建议，需验证通道和特征定义，不以当前 E01 成绩选择“更容易”的答案。
4. 拟合并冻结新任务头；完成 Q1–Q3 独立参考及随机对照有效性检查；先封存 B 的题面、评估规则与私有材料，再让 Distiller 学习 A。没有时间完成 Q2/Q3 时可新建 Q1 子任务，不能把缺失部分说成完成。
5. Actor 只得到研究问题、可执行资源和约束。擦除方法、参考数值、优选层、成功特征和完整答案脚本留在私有区。公开接口提供计算能力，不把目标实验路径全部代替 Actor 决策。

CBraMod 官方仓库提供公开预训练权重和自定义数据接入示例，但并不使新数据预处理和输出头自动匹配；本轮仍须逐项验证。[官方模型仓库](https://github.com/wjq-learning/CBraMod)

若 B 准备失败，应保留失败原因与可继续的资源清单。不能把 EEGMAT 换一个随机种子、特征或相邻层后称作独立新任务；这种补充最多支持较弱的同域迁移。

## 6. 如何判断 Agent 学到了科研方法

先不合成一个未经校准的 taste 总分。每条结果分别报告：

- **问题操作化**：是否写出可区分的竞争解释，以及哪项观测会使其放弃原解释。
- **实验选择**：是否主动选择真正有判别力的负对照、匹配干预或迁移验证；给定接口强制完成的步骤与 Agent 自主提出的步骤分开。
- **执行和证据**：是否实际运行、split 正确、无测试后选择、产物可重放，数值与主张对应。
- **解释纪律**：是否混淆恢复/使用/生理因果，是否把不显著说成无效，是否尊重小样本范围。
- **经验迁移与成本**：新题中对应错误是否减少，是否为此付出更多会话/计算，其他错误是否增加。

记录每个 episode 的真实输入，验证 skill 正文确实进入相应会话。历史上出现过“生成规则文件但未实际注入”的审核发现；仅有 skill 文件和配置开关不能证明干预发生。新比较还应控制额外文字长度/提醒效应，优先保留一个等长的一般研究提醒对照作为后续扩展；本夜样本不足时不把该机制区分说成已完成。

由不知道组别的审核者看去条件标记后的报告及证据；参考外但可验证的发现单列，不能机械判错。把“参考覆盖”“数值正确”“解释可靠”分开。保留旧分数，新版本只对预先登记的比较统一使用。

## 8. 本阶段明确不把什么当作主要进展

不以继续扩写通用工具平台、单纯增加单元测试、重复通过的合成演示、堆更多模型或等待代理配置改善来代替真实研究。也不把一次好的特征读出、一个高准确率或一份更长报告当成 Agent 科研能力提高。

下一次汇报应能顺着一条具体链条展示：**研究问题 → Actor 的关键决定 → 实际实验与对照 → 哪条解释被支持/排除 → 从这次经历提取了什么规则 → 在新的真实任务上发生了什么。** 这条链条中每个尚未完成的环节都应明确保留。
