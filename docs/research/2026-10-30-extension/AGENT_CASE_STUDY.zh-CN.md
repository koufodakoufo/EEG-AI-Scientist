# E05/E06 Agent 配对案例

**两个真实 Agent 回合完成了同一 EEGMAT 任务的 Q1 特征恢复分析，均未完成 Q2 干预响应和 Q3 残差信息。E06 的部分 Q1 数值更高，也花了更多原生会话时间；一个配对不足以确认技能收益。** 这是一项已完成执行的有限案例，不是研究计划或一般能力测量。

## 比较如何发生

冻结的 [comparison-v2 协议](COMPARISON_PROTOCOL_V2.json) 先安排 E05 无 skill、再安排 E06 固定 skill；两者共用数据划分、官方冻结 CBraMod、新增冻结二分类头、模型 `gpt-6.1-sol` medium、工具与每回合资源限制。E05 生命周期完成后才准入 E06。E01 属于旧协议下保留的失败，不能与 v2 合并成同一配对；预定反向顺序的 E07/E08 未启动。

技能来自 synthetic development 的 M15 蒸馏，冻结 SHA256 为 `54d5ce036ebb184bc653060196bed701807bb516b63dfc40d892d9938079191d`。E06 五个真实会话都记录该精确注入，E05 五次均无注入。它强调区分可恢复性、预测器响应与因果解释；本轮没有从真实任务轨迹生成新的技能，也没有测试递归自我改进。

实际链条可在 [集成验收](INTEGRATION_ACCEPTANCE.md) 中逐节点复核：两回合都从 brief、委托 scope review、contract、baseline，到 scientific attempt、锁定、一次测试、最终报告、done。E05 为 R60–R64，E06 为 R66–R70；每回合五次真实原生模型会话，而不是五个独立实验重复。Actor 只获本回合公开材料和自身历史，Builder 参考结果不算 Actor 成绩。

| test 正向描述性规则组合数 | 1 | 5 |
| test balanced accuracy / AUROC | 0.569444 / 0.643904 | 与 E05 完全相同，原始 logits 也精确相等 |
| 五次原生进程耗时总和 | 612.528 秒 | 1360.898 秒 |
| 生命周期与科学完成 | done；Q1 only | done；Q1 only |

正向描述性规则为 family-adjusted R² 下界及正减负差值 marginal CI 下界均大于零。它依赖原受信 bootstrap 近似区间，不是 Agent 能力总分，也不能把组合数差异解释成新的正式显著性结论。全部 24 组数值、负向结果、源哈希和检查方法见 [E06 与配对审计](E06_AND_PAIR_AUDIT.zh-CN.md)。

E06 在 layer 6 的 delta/theta log power、wavelet entropy、绝对相关均值以及 layer 12 的 wavelet entropy 达到该描述性规则，E05 仅 layer 6 的 wavelet entropy。E06 并非所有组都更好，例如 layer 6 绝对相关标准差 R² 从 E05 的 0.348501 降到 0.273609，layer 12 sample entropy 从 0.498788 降到 0.465724。两回合的 activity test R² 都严重为负（层 6：−5.046798；层 12：−3.696017），不能只挑较好的组合叙述。

E06 对 Q2/Q3 的解释区分了原型与已验证产物：局部数值检查通过，但完整干预 worker 时间未验证，原型 Ctrl-C 退出 130；这不证明算法一定超过 900 秒。第三原生会话 R68 自身 895.377 秒正常退出，账本及 native status 都是 completed。最终受信输出未含干预或残差，因此效应是**未估计**，不是零效应。

## 证据能支持什么

可支持的观察是：在相同任务资源上限下，这一次带技能的 Actor 选择了更细的组级探针策略、保留了更多方法比较和局部可行性历史；其若干 held-out Q1 恢复数值提高，同时有负向差异和更长的实际原生进程时间。两回合最终报告都承认可恢复性不等于任务依赖或生理因果。E06 自述技能影响了 estimand 分离，但自述不是技能因果效应证据。

不能支持“技能导致上述提高”：只有一个顺序配对，一个任务，没有独立条件重复，模型运行也未固定可重现随机种子。不同探针搜索、正则化与负对照会改变数值；这既可能是技能、也可能是运行间随机性或其他实际行为差异。单次诊断随机化尤其不能提供稳定的控制分布，24 个相关组不能替代独立 Actor 样本。进程耗时包括工具与等待，美元成本未知；不同机器负载下的 worker 时间不能当作算法速度或模型调用成本的精确因果效应。

科学推断限于少量参与者、固定 EEGMAT 情境、固定骨干/头、供给特征 panel 和有限探针族的可恢复性。验证和测试各六人，bootstrap 条件于一次训练拟合及固定验证选择；宽区间和 family 极端分位数近似必须保留。Q2/Q3 缺失，不支持任务依赖、有效信息移除、唯一生理机制或临床用途，也不支持通用能力改善、跨任务推广或 RSI。

## 审计强度与停止状态

E05 在此前完成了独立干净重放，逐数组和发布指标精确一致；E06 本次只对既有证据作独立哈希、源码阅读、报告表格与点估计核对，未进行新的模型执行或独立干净重放。两者都具有真实证据，但不能称为相同程度的方法复现。

用户晨间明确要求停止新研究后，本轮只完成结题审计和文档。E07/E08 未启动；没有为获得更好配对结果补跑、替换失败或调整原冻结协议。下一步研究的想法不计作已实现功能或已取得科学发现。
