# 方法迁移试验：问题、论文与参照

本页是 [研究主计划](ignition-study.md) 的任务映射。当前可执行的一对任务是
**EEGMAT → EEGMMIDB，跨数据集、同问题类型的方法迁移**。它们是改编研究，
不能称为 BrainPEC 原条件重发现，也不能据此宣称跨问题类型泛化或 ignition。
本页用于项目审阅；研究者只接收明确列入白名单的任务材料。

## 研究什么，怎样与论文比较

“模型保留什么信息”和“预测是否依赖这些信息”是两个不同问题。
BrainPEC 在 EEG 上组织了属性读出、表示干预和解释分析，为本次任务提供了
具体研究路线；我们的研究范围无需局限于某篇论文，也不要求 Agent 得出论文式的肯定结论。

| 可检验的主张 | BrainPEC 中的依据 | 当前任务要求的证据 | 不能据此推出什么 |
| --- | --- | --- | --- |
| 某属性能从表示中读出 | §3.2；§4.2；Appendix C.5 | 在未参与拟合的被试上，读出优于合理的随机对照，并报告不确定性 | 低线性读出分数不能证明完全没有信息；能读出不能证明预测依赖它 |
| 修改属性相关的表示成分影响预测 | §3.3；§4.3、Table 2；Appendix C.6–C.7 | 修改完整层张量，继续冻结模型的后续计算；与秩和扰动强度相当的随机修改比较 | 性能下降本身不能排除一般性损坏，不能证明脑内生理因果机制 |
| 干预后目标信息确实减少，且结论范围适当 | 干预方法及其局限讨论，Appendix C/D | 在修改后的表示上重新拟合读出，检查残留信息；联合解释读出、损坏对照和预测变化 | 单一探针失效不是完全擦除；不显著也不是证明没有依赖 |

论文依据：[BrainPEC v2](https://arxiv.org/html/2605.11410v2)。表中的证据要求是
本项目的评价设计，不将所有加强对照或统计选择归于原论文。

采用 FIRE 启发的**主张与证据逐项对齐**，而不是让 Agent 猜论文答案。
每条结论记录对象与条件、实验、比较对象、不确定性、证据位置和结论强度。
先核实 Agent 的证据，再区分三种比较：条件相同时的重发现；条件改变时的
一致或分歧；原论文未研究的新任务扩展。论文结论本身也可被有效证据质疑。
这不是声称已经实现 FIRE 的完整协议或评分体系。

## 当前两个任务

| 项目 | 来源任务：EEGMAT | 目标任务：EEGMMIDB |
| --- | --- | --- |
| 标识 | `eegmat-attribute-dependence-v1` | `eegmmidb-attribute-dependence-v1` |
| 研究对象 | 心算与背景条件的冻结分类模型 | R01 睁眼、R02 闭眼基线条件的冻结分类模型 |
| 模型 | 官方预训练 CBraMod；本项目新拟合并冻结的线性分类头 | 相同预训练骨干；针对本任务新拟合并冻结的线性分类头 |
| 分析范围 | 12 组属性、62 列；第 6、12 层；读出、干预、残留读出 | 相同分析接口与问题类型 |
| 数据划分 | 训练/验证/测试为 24/6/6 名被试，576/144/144 个窗口 | 同样的被试数和窗口数，独立数据集 |
| 论文关系 | 与 BrainPEC 的心算属性分析相关，但条件不同 | BrainPEC 原任务面板外的扩展 |
| 主要用途 | 产生真实独立研究轨迹，供更新过程总结方法 | 冻结更新后，比较无方法材料与改进方法的独立运行 |

两侧均为 5 秒、20 通道、200 Hz 的窗口，使用被试分组推断。
EEGMMIDB 从 160 Hz 重采样，只取每段前 60 秒；其 FCz 是实际测量的通道，
不能把它解释成 EEGMAT 的 A2−A1 输入槽含义。R01 始终先于 R02，眼状态与
记录顺序没有独立控制。两侧测试均只有六名被试，窗口数不能替代独立样本数。
共同事实和任务要求应对所有条件一致提供。

来源：[EEGMAT](https://physionet.org/content/eegmat/1.0.0/)、
[EEGMMIDB 1.0.0](https://physionet.org/content/eegmmidb/1.0.0/)。
本表的数据划分、通道适配和取窗方式是本项目已导出资产的条件，不是数据集的通用标准。

## 独立参照怎样使用

Builder 在测试 Actor 之前冻结任务资产与私有参照，研究者和方法更新过程均不接触
目标参照或目标测试答案。资产收据保留原始哈希，复制后再次核对；新目录不改写旧实验身份。

现有参照包含 24 个属性×层组合的读出结果，以及每侧两个通过开发数据选择的
干预范围；干预是在完整层张量上执行后继续模型计算，并包含三个匹配随机对照和残留读出。
独立核验重算保存的逐行预测及被试重采样区间。EEGMAT 另用预定的 12 行切片
检查完整模型计算，该切片不替代全测试重放。EEGMMIDB 因历史与云端环境出现细微
浮点差异，保留原严格容差检查的失败，并在云端对全部 144 行、原冻结的全部读出
和两个干预范围重新计算，另行冻结当前环境参照；没有重新拟合或重新选择。
这属于环境一致性核验，不是新增独立样本或第二份科研发现。

**参考不是强制方法或预设答案。** 只有对象、特征、层和分析定义匹配时才作数值对比。
Agent 选择了参照未覆盖的干预时，检查它的代码、冻结记录和可信评估输出；必要时在冻结后
独立重放，不因“没有参考数字”判错，也不在看到目标结果后改写评价标准。
负结果、排除错误解释和证据不足的结论均可有科学价值。

## 原条件重发现还缺什么

原论文下游检查点与分类头身份、预处理和被试划分、完整层选择范围，以及相应原始结果行
尚未匹配，因此直接重发现任务暂不计入已就绪任务。
目前代码中的 Stress 分类头含隐藏层，而论文描述中的线性分类头需要进一步核对。
论文同样描述冻结骨干，不能用“我们的模型冻结、论文全面微调”解释差异。
见固定版本的 [检查点说明](https://github.com/Kian-Chen/BrainPEC/blob/982b1df393a846e6418cee715bdfaa57d041cee3/inference/README.md)
和 [Stress 模型](https://github.com/Kian-Chen/BrainPEC/blob/982b1df393a846e6418cee715bdfaa57d041cee3/inference/models/stress.py)。

拿到匹配的模型、划分和结果行并由 Builder 重放后，才可加入原条件任务。
当前先完成可信的同问题类型迁移比较；之后再增加表示与读出瓶颈等不同问题类型。
