# Isolated launch contract

The formal repository is X:/projects/EEG-AI-Scientist. The same-origin server checkout is `/data/duandh/eegfm-stage-a-20261028/overnight-20261029/integration`. The older imported source snapshot remains untouched. Nothing is pushed.

Each Actor uses `scripts/overnight/actor_job.py` with a new M-number job, new case, fresh Codex home, and `codex exec`. Only the public bundle is copied into its case. No Builder messages, old sessions, project AGENTS, memories, repository, private reference, evaluator or other case is mounted. The Distiller uses the same boundary with a separate dev-only allowlist. The Builder reserves each model call in BUDGET.json before launching; rerunning an existing ID is rejected.

The isolated tool profile is validated by an actual M10 model invocation and command probes. Model control can use the existing loopback proxy; sandboxed tool subprocesses cannot use it, reach another local service or connect externally. Web, browser, computer, app/plugin, hosted skill discovery and multi-agent features are disabled. Generic MCP API helpers remain declared, but list calls are empty and unknown servers fail closed. This is a tested boundary, not a proof against every possible kernel or model exploit.

The native CLI and matching code-mode host are pinned by hash. CLI 0.165.0 ignores a selected profile when `--ignore-user-config` is also passed; that flag is therefore absent. Configuration isolation comes from the fresh home. The runtime needs read access to its exact native binary, read-only aliases and `tmp/arg0-linux` helper. Broadly denying the control parent overrode that exception, so the final profile uses default-denied paths and exact auth/config denies. M05/M07/M09 failed before scientific enrollment and remain recorded as infrastructure diagnostics.

CPU affinity is fixed to four allowed cores and widening is denied with inherited seccomp. The supervisor tracks descendants even if they start new process groups, terminates only its own children, and records survivors. Total episode wall time is 900 seconds. Physical RSS is sampled every 100 ms against 12 GiB; it is not a kernel cgroup ceiling. The V8 host reserves very large virtual address space, so virtual-address RLIMIT_AS is disabled only for model control. Output and owned-case storage are bounded and disk floor is 20 GiB. Analysis replay has a separate hard 60-second timeout per command. Original model-driven tool commands have the episode deadline plus a prompted 60-second command limit; there is no claim of an independently enforced 60-second limit on each original tool call.

Completed native traces are sanitized to retain visible messages and actual tool calls/results, excluding reasoning and account metadata. The protected original raw-file hash is recorded before sanitization. Authentication bytes are never copied into evidence. Collection freezes outputs without modifying them and runs submitted Python code only inside a fresh no-auth sandbox. Successful replay establishes reproducibility; semantic agreement, original execution provenance and scientific validity remain separate.
